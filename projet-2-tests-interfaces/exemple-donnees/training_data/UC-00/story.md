# Story : UC-00 — DEMO-1

## Titre
DEMO_STRY001_Réservation d'un livre par un abonné

## Statut Jira
80_COMPLETED

## Module
DEMO

## Description
EN TANT QU'abonné de la bibliothèque,

JE VEUX réserver un livre qui n'est pas disponible,

AFIN DE l'emprunter dès qu'il est rendu.

## Critères d'acceptation
À partir de la fiche d'un livre, l'abonné connecté clique sur le bouton « Réserver ».

S'assurer que :

- La page est conforme à la maquette ;
- Le bouton « Réserver » n'est visible que si le livre n'est pas disponible ;
- Après la réservation, le message « Votre réservation est confirmée » s'affiche ;
- La réservation apparaît dans l'onglet « Mes réservations » avec le titre, la date de réservation et le rang dans la file d'attente ;
- Un abonné ne peut pas réserver deux fois le même livre : le message « Vous avez déjà réservé ce livre » s'affiche.
