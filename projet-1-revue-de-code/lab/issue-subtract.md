# Add a subtraction function

As a user of the calculator, I want to subtract one number from another, so that I can compute differences.

## Acceptance criteria

- AC-1: `subtract(a, b)` is added to `example_app/calculator.py` and returns `a - b`.
- AC-2: `subtract` handles positive, negative, and decimal numbers.
- AC-3: unit tests cover the nominal, negative, and decimal cases.

## Constraints

The public signature `divide(a, b)` stays unchanged. No new dependency.
